## Shared Seeding Guidance

If the project has a seed script, update it when schema changes or required demonstration scenarios affect it. Verify that a fresh seed supports those scenarios. Before editing, read `docs/seeding.md` when present and follow the project's reset, rerun, and data-access conventions.
